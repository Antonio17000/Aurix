IMPORTANTE
Questa versione NON è ancora un'intelligenza artificiale vera e non invia messaggi a un modello AI.
La memoria è una singola nota salvata nel browser del dispositivo.
La ricerca apre Google con il testo scritto nella casella.
Il riconoscimento vocale dipende dal supporto del browser.

COME PUBBLICARLA
Per installarla come app su iPhone, i file devono essere pubblicati su un sito HTTPS.
GitHub non è indispensabile. Possiamo scegliere un servizio di hosting semplice in un passaggio successivo.
Dopo la pubblicazione: apri l'indirizzo in Safari > Condividi > Aggiungi alla schermata Home.

Non inserire password, codici o chiavi API nel codice.
